Drop your image files into this folder using these exact names so the site picks them up automatically:

LOGO
----
logo.png            -> Header logo mark (transparent PNG recommended, ~120x120px)

HERO BACKGROUND SLIDER (gallery)
---------------------------------
hero-1.jpg          -> Slide 1 background (e.g. tank installation / factory floor)
hero-2.jpg          -> Slide 2 background
hero-3.jpg          -> Slide 3 background
hero-4.jpg          -> Slide 4 background
hero-5.jpg          -> Slide 5 background
hero-6.jpg          -> Slide 6 background

Recommended size: at least 1920x1080px, landscape, JPG format, optimized for web (<400KB each).
The same images are used as the small thumbnail strip at the bottom of the hero, so pick photos
that read well both as a full background and as a small square crop (tanks, welding, installation,
team on site, finished projects, factory work, etc).

You can add more or fewer slides later -- just update the <div class="hero-slide"> /
<button class="thumb"> blocks in index.html and keep the data-bg paths matching the file names.
